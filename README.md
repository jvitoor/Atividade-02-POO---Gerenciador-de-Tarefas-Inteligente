# Gerenciador Inteligente de Tarefas (POO)
Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

## 1. Sobre o projeto
Este projeto é um sistema de gerenciamento de tarefas desenvolvido em Python aplicando os conceitos de Programação Orientada a Objetos. O sistema permite cadastrar usuários, criar projetos e gerenciar tarefas com prioridades, datas limites e status.

## 2. Funcionalidades
- Cadastro e remoção de Usuários
- Cadastro e remoção de Projetos
- Adição e conclusão de Tarefas (com prioridade e data limite)
- Relatórios de acompanhamento de progresso e porcentagem de conclusão
- Interface Interativa via CLI (Menu no Terminal)

## 3. Tecnologias utilizadas
- Linguagem de Programação: Python 3
- Paradigma de Programação Orientada a Objetos
- CLI (Terminal)

## 4. Como executar
1. Clone o repositório:
`git clone https://github.com/jvitoor/Atividade-02-POO---Gerenciador-de-Tarefas-Inteligente.git`
2. Execute o arquivo principal:
`atividade_2_poo.py`
